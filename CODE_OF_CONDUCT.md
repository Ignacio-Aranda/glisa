# Code of conduct

Glisa follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, welcome newcomers, and keep
discussions about the work. Harassment, insults, and personal or political attacks aren't
tolerated in issues, pull requests or any other project space.

To report a problem, contact the maintainer through GitHub (a private message, or a private
security advisory if it can't wait). Reports are handled confidentially.
